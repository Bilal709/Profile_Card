CSS Reflection

The spacing properties were the most confusing at first because margin creates space outside an element while padding creates space inside it. Border-radius became clearer once I saw it rounding the actual card and photo edges. Box-shadow took some experimenting, so I adjusted the blur and opacity until it looked soft instead of heavy. I resolved the responsive sizing by using width, max-width, and clamp() so the card still feels balanced at both 350px and 500px.
